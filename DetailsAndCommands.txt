deploy.yml copy this code 

name: Deploy Flask App

on:
  push:
    branches:
      - master

jobs:
  deploy:
    runs-on: ubuntu-latest

    steps:
      - name: Deploy to EC2
        uses: appleboy/ssh-action@v1.0.3
        with:
          host: ${{ secrets.EC2_HOST }}
          username: ${{ secrets.EC2_USER }}
          key: ${{ secrets.EC2_SSH_KEY }}
          script: |
            cd /home/ubuntu/CICDFlaskApp

            git pull origin master

            # Kill only the previous app.py process by its PID, not by name broadly
            if [ -f app.pid ]; then
              kill $(cat app.pid) || true
              rm app.pid
            fi
            
            source /home/ubuntu/venv/bin/activate

            # Start app and save its PID
            nohup python3 app.py > app.log 2>&1 &
            echo $! > app.pid

            echo "Deployment completed"

Now few questions 

what is uses: appleboy/ssh-action@v1.0.3
GitHub Actions doesn't know how to SSH by default. 
appleboy/ssh-action is a pre-built action (like a plugin) made by a developer 
named appleboy that handles SSH connection for you.


Explain this line nohup python3 app.py > app.log 2>&1 &
nohup   python3 app.py   > app.log   2>&1   &
  │           │               │        │     │
  │           │               │        │     └── Run in background
  │           │               │        └──  Merge errors into app.log
  │           │               └── Send output to app.log
  │           └── Run your flask app
  └── Don't stop when SSH session closes
